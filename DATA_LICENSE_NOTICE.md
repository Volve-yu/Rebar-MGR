# Dataset release notice

The `public_data/` directory contains the 500 images selected for release and their paired annotations. The full private dataset is not included. `data/`, if generated by the preparation script, is an ignored working copy of the same public subset.

This repository was assembled for the project workspace. No public redistribution license has been assumed for the imagery. If the owner does not authorize redistribution, remove `data/` and distribute only the schema, preprocessing code, and a controlled-access procedure.
