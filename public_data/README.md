# 公开钢筋数据子集

工地一 100 张、工地二 400 张，共 500 张 RGB 图像及 4173 条逐间距测量记录。

每张图使用统一编号，如 `工地一_0001`，对应文件为：

- `工地一/images/工地一_0001.jpg`：用户指定的 RGB 原图，未重新压缩。
- `工地一/segmentation/工地一_0001.png`：原人工分割掩码。
- `工地一/edge/工地一_0001.png`：原边缘标注。
- `工地一/rebar_labels/工地一_0001.txt`：按从左到右排列的钢筋中心横坐标，单位像素。
- `工地一/measurements/工地一_0001.csv`：该图逐间距实测值、区域、设计间距、上下允许偏差和激光距离。

工地二结构相同。间距及允许偏差单位为毫米，激光距离单位为米。下偏差为有符号负值。设计依据为空时继续保留空白，未补造规范出处或测量读数。

`samples.csv` 是图片和所有配套文件的索引；`measurements.csv` 汇总全部公开间距；`id_mapping.csv` 是公开编号与原编号的对应表；`validation.json` 记录检查结果。

选择规则：在用户指定的 `data-1`、`data-2` 中按数字文件名排序，从可核验对应原图的候选中取前 100、400 张，不按模型效果筛选。`data-1/101.jpg`、`data-2/574.jpg` 缺少同编号原始 PNG，未纳入。所有选定 JPG 解码后的 RGB 像素均与对应原始 PNG 逐像素一致，掩码和边缘图尺寸一致，中心数与间距数对应。

| 工地二 | 317 | 79 | 4 | 400 |

公开数据不是完整论文数据集，不能直接复现完整论文指标。14 张未分配图片仍提供配套标注，单列于 `gt_sets/unassigned.txt`，未擅自分入训练或验证集。实测来源是用户提供并核查的标注，发布处理不构成独立计量审核。
